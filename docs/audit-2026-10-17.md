## Checked and dismissed

- "The file input with `capture` is blocked by `Permissions-Policy:
  camera=()`": it is not, the policy governs getUserMedia only; the policy
  was still changed for the desktop webcam.
- "NVIDIA's text default can read images": it cannot, which is why
  `NVIDIA_VISION_MODEL` exists separately from `NVIDIA_MODEL`.
- "Business failures from an edge function should be 4xx/5xx": with
  supabase-js `functions.invoke` the page then loses the reason; the
  function answers 200 with `ok:false` after authentication, the way
  `ask-question` already does for a model that declines.
